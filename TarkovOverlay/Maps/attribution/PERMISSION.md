# Permission to use tarkov.dev site and data

Date: 2026-11-04

Chat: Telegram, **EFT TarkDev**

The user asked, in Russian, whether they could use the tarkov.dev site and its data while building their own program for Escape from Tarkov. EFT TarkDev answered yes, and asked to be sent a link to the program later.

Screenshot: [permission-eft-tarkdev-telegram.png](permission-eft-tarkdev-telegram.png)

This covers the Customs.svg raster by Shebuka (`the-hideout/tarkov-dev-svg-maps`, CC BY-NC-SA 4.0) shipped as the Customs GPS underlay, the interior floor crops of that same SVG under `Maps/interiors/`, and extract positions from `https://json.tarkov.dev/regular/maps`. See [SOURCE.md](SOURCE.md).
